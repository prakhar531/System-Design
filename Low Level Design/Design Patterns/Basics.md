# Design Pattern

## What is a Design Pattern?

- A **well-established solution** to frequently occurring software problems
- Popularized by the **Gang of Four (GoF)** book
- Contains **23 design patterns**
- These design patterns is in terms of oops. There can be different patterns in diffrent areas

### Types of Design Patterns

1. **Creational Design Patterns**

   - Different ways to create an object
   - Examples: _Singleton, Factory, Builder_

2. **Structural Design Patterns**

   - How to decide methods and attributes of a class
   - Examples: _Adapter, Bridge_

3. **Behavioral Design Patterns**

   - Implementation of behavior in a class
   - Examples: _Strategy, Iterator_

## Why Study Design Patterns?

- They follow all **principles of good design**
- Provide a **common language** for all software engineers. ie we can tell our fellow developers which approach to follow
